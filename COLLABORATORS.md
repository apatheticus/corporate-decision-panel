## Roles

**Maintainer** — Has merge access. Reviews and merges pull requests, triages issues, and steers project direction.

**Contributor** — Anyone who has had a pull request merged. Listed in git history and release notes.

## Path to Maintainer

Consistent, high-quality contributions over time may lead to a maintainer invitation. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to get involved.
