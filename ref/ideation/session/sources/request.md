# User Request

I want to use Claude Code Agent Teams to create a "Team of Teams" Agent Skill that realistically emulates a SMB's org structure to make decisions and answer questions on issues that come before the company. I need you to help me come up with the process, steps, and detailed, comprehensive technical instructions necessary to have an AI agent create the required components (front matter, instructions, prompts, templates, scripts, etc.) that will make up this skill.

The structure this "Team of Teams" will emulate will be the top two layers of the company's org structure. Starting at the top, There would be a CEO who has a COO, CFO, CAO, CTO, CISO, VP of Sales, and VP of Delivery. From there, each of those roles would have team leads performing the key functions that support that role. For example: the CFO might have a Controller (accounting/close), a Head of FP&A (planning/analytics), a Treasury/Cash manager (or embedded), an AP manager and/or an AR manager, a Tax accountant (internal lead + external firm). Each of these individual roles would have extensive knowledge of their domain, and would respond to/prioritize issues based their unique perspective of how to best serve the company's interests.

When any issue is presented to the CEO they would tell their team to evaluate it and provide their recommendations, which the CEO would then evaluate to make a final decision. To do that, each of the CEO's team members would give direction to their own teams to evaluate the issue, research relevant topics, identify risks/benefits, develop plans, establish guardrails, etc., to ultimately provide a defensible argument for or against the idea from their unique perspective.

The task I'm giving you is not to build the Agent Skill yourself. The task is to create the specifications for a separate agent to build it. I need you to think through how best to create this "Team of Teams" Agent Skill, what all it needs to include, how to design it, how it will function, how it will be used, and ultimately produce a detailed, comprehensive technical specification that is thorough and complete enough that it can be handed off to a separate dedicated AI agent to create the skill. The output must include the specification document in markdown (.md) format the separate, dedicated builder agent will derive its tasks from.
