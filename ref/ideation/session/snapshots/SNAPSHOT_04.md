## Report #2: The Engagement Model

The key innovation is framing the user interaction as a **two-dimensional control surface**:

**Depth (3 tiers):**
- Hallway Question (single C-suite consult, 3-5 sentences)
- Working Session (2-4 C-suite, ~1 page panel assessment)
- Board Meeting (full cascade, 3-5 page decision record)

**Width (4 CEO Decision Modes):**
- Guardian (risk-averse), Pioneer (growth-oriented), Architect (consensus-building), Analyst (data-driven)
- Modes are CEO synthesis prompt modifiers — underlying domain analysis is identical
- Multi-mode comparison reveals the "decision space"

**Invocation:** `/consult`, `/panel`, `/deliberate`, `/evaluate` + `--mode` and `--compare-modes` flags.

**Key insight:** "The difference between a quarterly novelty and a daily tool is whether the skill matches the user's engagement level to the decision's weight."
