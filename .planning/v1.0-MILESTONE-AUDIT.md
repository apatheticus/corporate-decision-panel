### Phase 4: Scale and Docs

1. **session.py CLI entry point** (DOC-01, DOC-03) — `scripts/session.py` has no `main()`, `argparse`, or `if __name__ == '__main__'` block. Documentation in `infographics.md`, `ceo.md`, and `SKILL.md` says "call scripts/session.py" but the module must be invoked via Python import (`from scripts.session import run_session`). An agent running `python -m scripts.session` gets silent exit code 0. Fix: add CLI interface or update docs to show import pattern.
