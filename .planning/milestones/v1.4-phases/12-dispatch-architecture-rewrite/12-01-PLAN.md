2. **Sub-Question File Convention:**
   - Directory: `{session}/sub-questions/{role}/` (e.g., `{session}/sub-questions/cfo/`)

   ```

   [3-5 sentences summarizing CEO framing and any relevant Research Dossier findings]

   [Domain-specific translated question for this team lead]
   ## Output Instruction
   Follow the analytical framework and output template defined in your agent definition...
   ## Reference Files
   - Session: {absolute-session-path}
   - Record: {absolute-session-path}/RECORD.md (if exists)
   ```
4. **Notification Protocol:**
   - After writing all sub-question files: SendMessage CEO: "Sub-questions ready: {list of file paths written}"
   - No-team-leads path: SendMessage CEO: "No team leads needed -- proceeding with inline analysis"
5. **Relevance Filtering:** Not every question requires all team leads. Write sub-question files ONLY for relevant team leads. Absence of a file = team lead not relevant.
6. **Failure Handling:** Preserve existing failure handling guidance (partial analysis with explicit gap note).
