from google.genai import types

client = genai.Client(api_key=api_key)
response = client.models.generate_content(
    model=model_id,
    contents=prompt_text,
    config=types.GenerateContentConfig(
        response_modalities=["TEXT", "IMAGE"],
        image_config=types.ImageConfig(aspect_ratio="4:3", image_size="2K"),
        # Optional: thinking_config=types.ThinkingConfig(thinking_level="High")
    ),
)
for part in response.parts:
    if part.inline_data is not None:
        image = part.as_image()  # returns PIL Image
        image.save("output.png")

    6. **generate_infographic function:**
    ```python
    def generate_infographic(
        infographic_type: str,
        data_path: Path,
        output_path: Path,
        skip_preflight: bool = False,
        config_dir: Path = Path(".cdp-context"),
    ) -> GenerationResult:
    ```
    Steps:
    a. Normalize type slug (lowercase, underscores to hyphens, strip)
    b. If not skip_preflight: run_preflight(config_dir). If not success, return GenerationResult(success=False, error_code=result.error_code). Print "PREFLIGHT FAILED" status.
    c. Load config via load_config(config_dir)
    d. Load template via load_template(type_slug)
    e. Load data JSON from data_path (json.loads(data_path.read_text()))
    f. Check for .cdp-context/style.md -- if exists, read as style_override
    g. Serialize template: prompt = serialize_template(template, data, style_override)
    h. Save prompt to output_path.parent via save_prompt()
    i. _status("GENERATING", type_slug)
    j. _status("PROMPT", "assembled")
    k. Create genai.Client(api_key=config["api_key"])
    l. Look up aspect_ratio from ASPECT_RATIOS (default "16:9" for unknown types)
    m. Build config via _build_config(type_slug, aspect_ratio, config["model_id"])
    n. Call client.models.generate_content(model=config["model_id"], contents=prompt, config=gen_config)
    o. Iterate response.parts for inline_data -- extract first image via part.as_image()
    p. If no image found in response: return GenerationResult(success=False, error_code="NO_IMAGE_IN_RESPONSE")
    q. output_path.parent.mkdir(parents=True, exist_ok=True)
    r. image.save(str(output_path))
    s. _status("IMAGE", "received")
    t. _status("SAVED", str(output_path))
    u. Return GenerationResult(success=True, output_path=output_path, prompt_path=prompt_path)

    Wrap the API call in try/except for ClientError -- on failure return GenerationResult(success=False, error_code=f"API_ERROR_{e.code}"). Phase 3 adds retry logic; Phase 2 just reports the error.
