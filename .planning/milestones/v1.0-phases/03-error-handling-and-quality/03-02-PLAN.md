  <name>Task 1: generate_with_retry wrapper with exponential backoff and corrective feedback</name>
  <files>scripts/generate_infographic.py, tests/test_generate_infographic.py</files>
  <behavior>
    - generate_with_retry(infographic_type, data_path, output_path, retry_limit=2, config_dir=...) returns GenerationResult
    - On success: runs vision validation; if validation passes, returns success result
    - On success + validation warning_only: returns success result (warnings are OK)
    - On success + validation failure: retries with corrective feedback appended via style_override_extra parameter; consumes from retry budget
    - On retryable API error (429/503/500): calls _backoff(attempt), retries; consumes from retry budget
    - On content block: immediately calls create_placeholder_png with "BLOCKED: content policy" text, saves PROMPT.json, returns failure -- NO retry
    - On budget exhaustion (all attempts used): calls create_placeholder_png with "{type} -- Generation Failed" text, saves PROMPT.json, returns failure
    - _backoff(attempt, base_delay=2.0, max_delay=30.0) sleeps for min(base * 2^attempt, max) + jitter (random.uniform 0 to 50% of delay)
    - _backoff returns the actual delay slept (for logging/testing)
    - Preflight runs only on first attempt (skip_preflight=True for retries)
    - genai.Client created with HttpRetryOptions(attempts=1) to disable SDK retry
    - Placeholder PNG uses type-specific dimensions from ASPECT_RATIOS (4:3 -> 1440x1080, 16:9 -> 1920x1080)
    - generate_infographic() gets a new optional parameter style_override_extra: str | None for appending corrective feedback
  </behavior>
  <action>
    Modify scripts/generate_infographic.py:

    1. Add `import random, time` to imports.

    2. Add `_backoff(attempt: int, base_delay: float = 2.0, max_delay: float = 30.0) -> float` function. Calculate `delay = min(base_delay * (2 ** attempt), max_delay)`, add `jitter = random.uniform(0, delay * 0.5)`, sleep for `delay + jitter`, return actual delay.

    3. Update `generate_infographic()` signature to accept `style_override_extra: str | None = None`. In the style override section (step 4), if style_override_extra is provided, append it to style_override (or use it as style_override if no style.md exists). This allows the retry loop to inject corrective feedback into the prompt.

    4. Update `generate_infographic()` to create the genai.Client with `http_options=types.HttpOptions(retry_options=types.HttpRetryOptions(attempts=1))` to disable SDK's built-in retry. This prevents double-retry (SDK retry x app retry = exponential explosion per RESEARCH.md Pitfall 1).

    5. Add `generate_with_retry(infographic_type: str, data_path: Path, output_path: Path, retry_limit: int = 2, config_dir: Path = Path(".cdp-context")) -> GenerationResult`:
       - `max_attempts = retry_limit + 1`
       - `corrective_feedback: str | None = None`
       - Loop `for attempt in range(max_attempts)`:
         - Call `generate_infographic(infographic_type, data_path, output_path, skip_preflight=(attempt > 0), config_dir=config_dir, style_override_extra=corrective_feedback)`
         - If `not result.success`:
           - If `_is_content_block(result.error_code)`: create placeholder with "BLOCKED: content policy" + type-specific dimensions, save PROMPT.json with error_code, `_status("BLOCKED", type_slug)`, return failure -- NO retry
           - If `_is_retryable_error(result.error_code)` and not last attempt: `_status("RETRY", f"{type_slug} attempt {attempt+2}/{max_attempts}")`, `_backoff(attempt)`, continue
           - Else (non-retryable or budget exhausted): create placeholder with "{TYPE} -- Generation Failed", save PROMPT.json, `_status("FAILED", type_slug)`, return failure
         - If `result.success`:
           - Call `validate_infographic(result.output_path, data_path, config_dir)` from scripts.validation
           - If `validation.passed` (including `warning_only`): `_status("VALIDATED", type_slug + (" (warnings)" if validation.warning_only else ""))`, return result
           - If `not validation.passed` and not last attempt: `corrective_feedback = validation.feedback`, `_status("VALIDATION_FAILED", f"{type_slug} -- retrying with feedback")`, continue
           - If last attempt: return result (image exists but didn't pass validation -- still return the image)
       - Return result (should not reach here)

    6. Determine placeholder dimensions from ASPECT_RATIOS: if type's ratio is "4:3", use 1440x1080; otherwise 1920x1080.

    Add test classes to tests/test_generate_infographic.py:
    - `TestRetry`: Mock generate_infographic to fail with API_ERROR_429 twice then succeed. Verify generate_with_retry succeeds on 3rd attempt. Verify _backoff was called twice. Mock time.sleep to avoid actual delays.
    - `TestRetryBudgetExhausted`: Mock generate_infographic to fail with API_ERROR_429 3 times (budget=2). Verify placeholder PNG created, PROMPT.json saved, result.success is False.
    - `TestContentBlockNoRetry`: Mock generate_infographic to return CONTENT_BLOCKED_SAFETY. Verify NO retry attempted (generate_infographic called exactly once). Verify placeholder has "BLOCKED: content policy" text.
    - `TestRetryWithFeedback`: Mock generate_infographic to succeed but validate_infographic to fail with feedback. Verify second call to generate_infographic includes the corrective feedback. Mock validate_infographic to pass on 2nd call.
    - `TestBackoff`: Verify _backoff calculates correct delays: attempt 0 -> ~2-3s, attempt 1 -> ~4-6s, attempt 2 -> ~8-12s. Mock time.sleep and random.uniform.
    - `TestSDKRetryDisabled`: Verify generate_infographic creates Client with HttpRetryOptions(attempts=1).

    For all retry tests, mock `time.sleep` to avoid real delays and mock `random.uniform` for deterministic jitter in backoff tests.

<task type="auto" tdd="true">
  <name>Task 2: Session orchestrator with inter-call delay, adaptive 429 handling, and summary table</name>
  <files>scripts/session.py, tests/test_session.py</files>
  <behavior>
    - SessionResult dataclass has: results (dict mapping type_slug to GenerationResult), summary_lines (list[str]), any_succeeded (bool), total_types (int)
    - run_session(types_list, data_paths, output_dir, config_dir) iterates over types, calls generate_with_retry for each, applies inter-call delay between ALL API calls
    - Default inter-call delay is 4 seconds (hardcoded, per research recommendation)
    - If any generate_with_retry result has API_ERROR_429 error_code, inter-call delay doubles for remaining images (adaptive delay)
    - Session continues past individual failures (one failure does not block remaining)
    - After all types processed, prints summary table in SUMMARY format with status lines
    - Status values: OK (success, no warnings), OK+WARN (success with validation warnings), FAILED (budget exhausted), BLOCKED (content block)
    - Exit code: 0 if any_succeeded is True, 1 if all failed
    - Summary shows attempts used as "{used}/{max}" format
    - Inter-call delay applied BETWEEN images (not before first, not after last)
    - run_session reads retry_limit from config via load_config
  </behavior>
  <action>
    Create scripts/session.py:

    1. Imports: `from __future__ import annotations`, `import time`, `from dataclasses import dataclass, field`, `from pathlib import Path`.

    2. `@dataclass SessionResult` with: results (dict[str, GenerationResult]), summary_lines (list[str], default_factory=list), any_succeeded (bool, default False), total_types (int, default 0).

    3. `_format_summary_line(type_slug: str, status: str, attempts: int, max_attempts: int, output_path: Path | None) -> str` -- Formats a single summary line: `"SUMMARY {type_slug:<30s} {status:<10s} {attempts}/{max_attempts}  {path}"`. Pads for alignment.

    4. `run_session(types_list: list[str], data_paths: dict[str, Path], output_dir: Path, config_dir: Path = Path(".cdp-context")) -> SessionResult`:
       - Load config to get retry_limit
       - `max_attempts = retry_limit + 1`
       - `inter_call_delay = 4.0` (hardcoded per research recommendation)
       - `results: dict[str, GenerationResult] = {}`
       - For each (i, type_slug) in enumerate(types_list):
         - If i > 0: `time.sleep(inter_call_delay)` (delay BETWEEN images, not before first)
         - `_status("SESSION", f"generating {type_slug} ({i+1}/{len(types_list)})")`
         - `data_path = data_paths[type_slug]`
         - `output_path = output_dir / f"INFOGRAPHIC_{type_slug}.png"`
         - Call `generate_with_retry(type_slug, data_path, output_path, retry_limit, config_dir)`
         - Store result in results dict
         - If result has 429 error: `inter_call_delay *= 2`, `_status("RATE_LIMIT", f"doubling inter-call delay to {inter_call_delay}s")`
       - After loop, build summary:
         - `_status("SUMMARY", "-------")`
         - For each result: determine status (OK/OK+WARN/FAILED/BLOCKED), format line, print, collect
         - `_status("SUMMARY", "-------")`
       - `any_succeeded = any(r.success for r in results.values())`
       - Return SessionResult

    5. Import `_status` from generate_infographic and `generate_with_retry` from generate_infographic, `load_config` from config.

Set it to True in generate_with_retry when a 429 retry occurs. The session checks this field.

    - `TestSessionContinuesOnFailure`: Mock generate_with_retry to fail for type 2 of 3. Verify types 1 and 3 still attempted.
    - `TestSessionSummary`: Run with mixed results (OK, FAILED, BLOCKED). Verify summary_lines contain correct status strings. Verify any_succeeded is True if at least one OK.
    - `TestSessionAllFailed`: All 3 types fail. Verify any_succeeded is False.
    - `TestSessionExitCode`: Verify exit code logic: 0 if any_succeeded, 1 if not.

    Mock time.sleep in all tests to avoid real delays.
