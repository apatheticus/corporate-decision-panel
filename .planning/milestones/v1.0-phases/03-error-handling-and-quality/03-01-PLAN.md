  <name>Task 2: Vision quality validation module</name>
  <files>scripts/validation.py, tests/test_validation.py, tests/conftest.py</files>
  <behavior>
    - ValidationResult dataclass has: passed (bool), warning_only (bool), feedback (str | None), warnings (list[str]), missing (list[str])
    - _extract_expected_labels(data: dict) extracts string values from the data dict as expected labels (filters out numeric-only values; splits long strings at semicolons/commas if they contain multiple items)
    - _parse_validation_response(text: str) parses "VERDICT: PASS|FAIL" + "WARNINGS: ..." + "MISSING: ..." + "FEEDBACK: ..." from vision model response text
    - _parse_validation_response with "VERDICT: PASS" returns ValidationResult(passed=True, warning_only=False)
    - _parse_validation_response with "VERDICT: PASS" + "WARNINGS: Label X truncated" returns ValidationResult(passed=True, warning_only=True, warnings=["Label X truncated"])
    - _parse_validation_response with "VERDICT: FAIL" + "MISSING: Label Y" + "FEEDBACK: Ensure Label Y appears clearly" returns ValidationResult(passed=False, feedback="Ensure Label Y appears clearly", missing=["Label Y"])
    - validate_infographic(image_path, data_path, config_dir) sends image bytes + structured prompt to Gemini vision, returns ValidationResult
    - validate_infographic creates client with HttpRetryOptions(attempts=1) to disable SDK retry
    - validate_infographic uses response_modalities=["TEXT"] for text-only validation response
  </behavior>
  <action>
    Create scripts/validation.py:

    1. `@dataclass ValidationResult` with fields: passed (bool), warning_only (bool, default False), feedback (str | None, default None), warnings (list[str], default_factory=list), missing (list[str], default_factory=list).

    2. `_extract_expected_labels(data: dict) -> list[str]` -- Iterate over data dict values, skip numeric-only values. For string values, if they contain semicolons or commas indicating multiple items (like "Finance: Approve (High), Legal: Oppose (Medium)"), split on ", " and include sub-items. Return a deduplicated list of labels. This provides the expected data labels for vision verification.

    3. `_parse_validation_response(text: str) -> ValidationResult` -- Parse structured response:
       - Look for "VERDICT: PASS" or "VERDICT: FAIL" (case-insensitive)
       - Extract WARNINGS line content (split on commas, strip "none")
       - Extract MISSING line content (split on commas, strip "none")
       - Extract FEEDBACK line content
       - If VERDICT=PASS and warnings exist, set warning_only=True
       - If unparseable, return ValidationResult(passed=True, warning_only=True, feedback="Validation response unparseable -- treating as pass with warning")

    4. `validate_infographic(image_path: Path, data_path: Path, config_dir: Path) -> ValidationResult` -- Load config, create client with HttpRetryOptions(attempts=1), read image bytes and data JSON, extract expected labels, build structured validation prompt (per RESEARCH.md Pattern 5 format), call generate_content with response_modalities=["TEXT"], parse response. Wrap in try/except for API errors -- on failure, return passed=True with warning (validation failure should not block generation).

    5. Add `_status()` calls: "VALIDATING {type_slug}" before API call, "VALIDATION PASS|FAIL|WARN" after.

    Create tests/test_validation.py with test classes:
    - `TestLabelExtraction` -- tests for _extract_expected_labels with various data shapes
    - `TestResponseParsing` -- tests for _parse_validation_response with PASS, FAIL, WARN, and malformed responses
    - `TestValidateInfographic` -- tests with mocked genai client for successful validation, failed validation, API error during validation

    Add to tests/conftest.py:
    - `mock_validation_pass_response()` -- mock text response with "VERDICT: PASS\nWARNINGS: none\nMISSING: none\nFEEDBACK: none"
    - `mock_validation_fail_response()` -- mock text response with "VERDICT: FAIL\nWARNINGS: none\nMISSING: Revenue label\nFEEDBACK: Ensure Revenue label appears clearly"
